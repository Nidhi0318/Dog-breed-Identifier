# 🐶 Dog Breed Identifier

## 🚀 Features
- Upload dog image
- Predict breed using CNN
- Shows confidence %

## 🛠 Tech Stack
- Python
- Flask
- TensorFlow

## ▶️ How to Run
python -m venv venv
venv\Scripts\activate
pip install flask flask-cors tensorflow numpy pillow
python app.py
##Test in browser
http://127.0.0.1:5000
You should see:
Dog Breed Predictor API is running!
